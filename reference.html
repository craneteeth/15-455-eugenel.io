Definitions and Results

Notation

Symbols are used with the same meaning on every page. The last column links to where each is introduced.

SymbolMeaningIntroduced in
$n$, $N = 2^n$number of input bits; number of strings searched
$f$, $M$, $t$the function searched, its set of marked strings, $t = \abs M$
$x^*$the marked string when $t = 1$
$\ket x$, $\ket\psi$, $\alpha_x$basic state, general state, amplitude of $\ket x$ (normalized)
$\ket s$uniform state $\frac1{\sqrt N}\sum_x\ket x$
$\braket{\varphi}{\psi}$, $\norm{\cdot}$inner product and length
$O_f$the query "if $f$ then minus"
$D$ReflectAcrossAverage, $2\ket s\!\bra s - I$
$\ket G$, $\ket B$, $\ket\varphi$uniform over marked / unmarked strings; unit vector at angle $\varphi$ in their plane
$\theta$angle with $\sin\theta = \sqrt{t/N}$
$k$, $k^*$number of Grover iterations; the choice $\lfloor\pi/(4\theta)\rfloor$
$T$, $U_j$number of queries of a general algorithm; its query-free steps
$O_x$, $\Pi_x$, $\Pi_{x,1}$query when only $x$ is marked; projections onto query register $= x$ (and control $=1$)
$\ket{\psi^x}$, $\ket{\psi^\emptyset}$final states with only $x$ marked / nothing marked
$\ket{\varphi_t}$, $\ket{H_j}$empty-run state before query $t$; hybrid runs
$q_x(t)$, $Q_x$query magnitude of $x$ at query $t$; total over $t$
