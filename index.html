Grover's Algorithm

CS455 Fall 2026 · Final projectGrover's algorithm and quantum query complexity

1Why Grover matters

An unstructured search over N possibilities takes Θ(N) classical oracle queries in the worst case. Grover’s quantum algorithm finds a marked item using Θ(√N) queries, and this quadratic speedup is optimal in the black-box model. For SAT on n variables, the naive quantum enumeration scale becomes roughly 2n/2 instead of 2n (ignoring polynomial verification costs).

Prerequisites. Familiarity with P, NP, randomized algorithms and asymptotic notation at the CS455 level. We briefly review normalized amplitudes, Hadamard transforms and unitarity before using them. No prior quantum-mechanics course is assumed.

Reading path. First understand why the phase oracle changes a sign and the diffusion operator reflects amplitudes about their mean. Then follow the two-dimensional rotation proof for the exact success probability. Finally, prove the Ω(√N) quantum query lower bound by the BBBV hybrid argument and examine what this means (and does not mean) for complexity classes.

One distinction to keep in mind

Grover’s lower bound applies to algorithms that access the search function only as an oracle. It does not prove exponential running-time lower bounds for algorithms that exploit the structure of an explicit SAT formula.

2Part I — The algorithm and exact analysis

The course’s “Add & Dif,” “Avg & Dev,” “if f then minus,” and “ReflectAcrossAverage” become precise linear-algebra operations. We derive the exact amplitude-amplification formula rather than relying on the approximate 1, 3, 5, … pattern.

3.1Introduction

In Lecture 9 we met Grover's algorithm through the lens of the Hadamard transform. The key subroutine, ReflectAcrossAverage, sends every amplitude α+δ\alpha + \delta to α−δ\alpha - \delta, where α\alpha is the average amplitude. Alternating it with "if ff then minus" made the amplitude of the hidden string grow like 1,3,5,7,…1, 3, 5, 7, \dots, and after about N\sqrt N rounds we could extract the answer with decent probability. That analysis was deliberately loose: every step said "basically", and we were promised a cleaner, geometric treatment later.

This page delivers that treatment and uses it to pin down the query complexity of search exactly. It is the first half of the project. Part II then asks what this algorithm means for complexity theory: where quantum computation sits among the classes we know, whether a quantum computer can solve NP\NP-complete problems efficiently, and why the answer "not by brute force" can actually be proved.

3.2Quantum Basics, as Vectors

We only need a small slice of the quantum model from Lectures 7–9, rewritten in the vector notation used by the wider literature. Nothing here is new physics; it is bookkeeping that makes the later geometry and the lower-bound proof in Part II easy to state.

States

An nn-qubit state assigns an amplitude to each of the N=2nN = 2^n basic states ∣x⟩\ket{x}, x∈{0,1}nx \in \{0,1\}^n. In the course we kept amplitudes unnormalized: after "Add & Dif all" on fresh qubits every amplitude is 11, the total squared amplitude is NN, and "extract all" prints xx with probability proportional to the squared amplitude of ∣x⟩\ket x. From now on we divide by the square root of the total, so that probabilities are the squared amplitudes themselves.

Definition — States as vectors

A state of nn qubits is a vector ∣ψ⟩=∑x∈{0,1}nαx∣x⟩\ket\psi = \sum_{x\in\{0,1\}^n} \alpha_x \ket x with ∑xαx2=1\sum_x \alpha_x^2 = 1. "Extract all" prints xx with probability αx2\alpha_x^2. The uniform state is

∣s⟩=1N∑x∈{0,1}n∣x⟩,\ket s = \frac{1}{\sqrt N}\sum_{x\in\{0,1\}^n}\ket x ,

the normalized version of what "Add & Dif all" produces from ∣0⋯0⟩\ket{0\cdots0}.

The course only ever used real amplitudes, and so will we. Every argument on this site goes through unchanged for complex amplitudes if αx2\alpha_x^2 is replaced by ∣αx∣2\abs{\alpha_x}^2.

We treat states as vectors in RN\R^N, with the usual inner product and length:

⟨φ|ψ⟩=∑xφxψx,∥∣ψ⟩∥=⟨ψ|ψ⟩.\braket{\varphi}{\psi} = \sum_x \varphi_x \psi_x, \qquad \norm{\ket\psi} = \sqrt{\braket{\psi}{\psi}} .

A state is just a vector of length 11. We also use the shorthand ∣s⟩ ⁣⟨s∣\ket{s}\!\bra{s} for the map ∣v⟩↦⟨s|v⟩∣s⟩\ket v \mapsto \braket{s}{v}\ket s, the projection onto the direction of ∣s⟩\ket s.

Instructions are unitary

Lecture 7 observed that each instruction we use preserves the total squared amplitude, once "Add & Dif" and "Avg & Dev" are rescaled to the Hadamard instruction. Each instruction is also linear (it acts on a superposition by acting on each basic state and superposing the results). A linear map UU with ∥U∣v⟩∥=∥∣v⟩∥\norm{U\ket v} = \norm{\ket v} for all vv is called unitary. Unitaries also preserve inner products, because ⟨u|v⟩=14(∥u+v∥2−∥u−v∥2)\braket{u}{v} = \tfrac14\left(\norm{u+v}^2 - \norm{u-v}^2\right), so they preserve lengths, angles and distances.

3.3Unstructured Search and the Query Model

Brute-force search is the most basic algorithm in computer science: to find a satisfying assignment of a formula on nn variables, try all 2n2^n of them. In Lecture 9 this was the problem Unique-SAT, where ff is given as AND/OR/NOT code CC with LL lines. One evaluation of ff costs O(L)O(L) steps, so brute force costs about L⋅2nL\cdot 2^n. The question here is how much better we can do if we refuse to look inside CC and only evaluate it.

Definition — Unstructured search

Let f:{0,1}n→{0,1}f : \{0,1\}^n \to \{0,1\}, let N=2nN = 2^n, and let M={x:f(x)=1}M = \{x : f(x) = 1\} be the set of marked strings, with t=∣M∣t = \abs{M}. The search problem is: given access to ff with t≥1t \ge 1, output some x∈Mx \in M. Unique search is the special case t=1t = 1, where we write x∗x^* for the unique marked string.

Definition — Query

A query is one application of the instruction "if ff then minus", that is, of OfO_f, to nn designated query qubits, while any other qubits are left alone. An algorithm in the query model may use any instructions it likes, but it may access ff only through queries. Its cost is the number of queries it makes.

A quantum query can act on a superposition of many strings at once. That is the whole source of the speedup, and also what makes lower bounds in Part II nontrivial.

Remark — Why count queries?

There are two reasons. First, query bounds translate into time bounds: if ff is given by code with LL lines, each query can be implemented with O(L)O(L) instructions (the course's recipe for turning classical code into "if ff then minus"), so an algorithm with qq queries and rr other instructions runs in time O(qL+r)O(qL + r). Second, and more important for a complexity class, in this model we can prove lower bounds. Proving that SAT needs exponential time is far beyond current techniques; proving that SAT needs many evaluations when the formula is a black box is the content of Part II.

Remark — Minus versus toggle

One can also access ff through "if ff then toggle Ans". Nothing changes: Lecture 8's analysis of MysteryToggles showed that if Ans is first prepared with amplitude +1+1 on ∣0⟩\ket 0 and −1-1 on ∣1⟩\ket 1, then "if ff then toggle Ans" acts exactly as "if ff then minus" on the query qubits. Conversely "if ff then minus" is all Grover's algorithm uses. So the two query types cost the same up to a constant.

The classical baseline

Proposition — Classical search needs about N queries

For unique search on NN strings:

  1. every deterministic algorithm makes at least N−1N - 1 queries on some input;
  2. every randomized algorithm that outputs x∗x^* with probability at least 2/32/3 on every input makes at least 23N−1\tfrac23 N - 1 queries on some input.

(1) Play adversary: answer 00 to every query. If the algorithm stops after at most N−2N-2 queries, at least two strings were never queried, and it outputs at most one of them. Mark the other one. Every answer we gave is consistent with this ff, so the algorithm is wrong on it.

(2) A randomized algorithm is a probability distribution over deterministic ones, so it suffices to show that every deterministic algorithm AA with qq queries succeeds with probability at most (q+1)/N(q+1)/N when x∗x^* is uniformly random. Run AA with every answer equal to 00. This determines a fixed list of queried strings y1,…,yqy_1,\dots,y_q and a fixed output zz. On the actual input, AA follows the same run until a query hits x∗x^*, so it can succeed only if x∗∈{y1,…,yq,z}x^* \in \{y_1,\dots,y_q,z\}, which has probability at most (q+1)/N(q+1)/N. Averaging over the algorithm's random choices, if every input is solved with probability ≥2/3\ge 2/3 then so is a random input, hence (q+1)/N≥2/3(q+1)/N \ge 2/3.

So classically, search costs Θ(N)\Theta(N) queries, and the next sections bring this down to O(N)O(\sqrt N).

3.4Grover's Algorithm

Here is the algorithm from Lecture 9, with the number of rounds left as a parameter kk to be chosen in Query Complexity of Search.

Note — Grover's algorithm with k iterations
  1. new qubit X1, …, Xn
  2. Add & Dif all # uniform superposition
  3. repeat kk times: # one "Grover iteration" per round
  4. if ff(X1, …, Xn) then minus # one query
  5. ReflectAcrossAverage(X1, …, Xn)
  6. extract all

In vector form, the final state is (D Of)k∣s⟩(D\,O_f)^k \ket s. The algorithm makes exactly kk queries and O(nk)O(nk) other instructions.

To analyze it we first describe ReflectAcrossAverage as a vector operation. Lecture 9 proved, through the Hadamard transform, that it maps each amplitude αx\alpha_x to 2αˉ−αx2\bar\alpha - \alpha_x, where αˉ\bar\alpha is the average amplitude.

Lemma — ReflectAcrossAverage is a reflection

ReflectAcrossAverage acts as D=2∣s⟩ ⁣⟨s∣−ID = 2\ket s\!\bra s - I. Equivalently, DD fixes ∣s⟩\ket s and negates every vector orthogonal to ∣s⟩\ket s.

For ∣ψ⟩=∑xαx∣x⟩\ket\psi = \sum_x \alpha_x\ket x we have ⟨s|ψ⟩=1N∑xαx=N αˉ\braket{s}{\psi} = \frac{1}{\sqrt N}\sum_x \alpha_x = \sqrt N\,\bar\alpha, so the xx-coordinate of 2∣s⟩ ⁣⟨s|ψ⟩2\ket s\!\braket{s}{\psi} is 2⋅1N⋅N αˉ=2αˉ2\cdot\frac{1}{\sqrt N}\cdot\sqrt N\,\bar\alpha = 2\bar\alpha. Hence (2∣s⟩ ⁣⟨s∣−I)∣ψ⟩(2\ket s\!\bra s - I)\ket\psi has xx-coordinate 2αˉ−αx2\bar\alpha - \alpha_x, which is Lecture 9's formula. For the second sentence: D∣s⟩=2∣s⟩−∣s⟩=∣s⟩D\ket s = 2\ket s - \ket s = \ket s, and if ⟨s|v⟩=0\braket{s}{v} = 0 then D∣v⟩=−∣v⟩D\ket v = -\ket v.

Note what "orthogonal to ∣s⟩\ket s" means concretely: a vector is orthogonal to ∣s⟩\ket s exactly when its amplitudes average to 00. So DD keeps the average and flips all the deviations from it, which is Lecture 9's picture again.

The next lemma is the structural fact that makes the whole analysis two-dimensional.

Lemma — Two numbers suffice

Suppose a state gives one common amplitude aa to every marked string and one common amplitude bb to every unmarked string. Then after "if ff then minus" and after ReflectAcrossAverage, the state again has this form. In particular, at every point of Grover's algorithm the state is described by a pair (a,b)(a, b).

"If ff then minus" sends (a,b)(a,b) to (−a,b)(-a, b). For ReflectAcrossAverage, the average is αˉ=(ta+(N−t)b)/N\bar\alpha = (ta + (N-t)b)/N, and every amplitude αx\alpha_x becomes 2αˉ−αx2\bar\alpha - \alpha_x, which depends only on αx\alpha_x. So all marked strings get 2αˉ−a2\bar\alpha - a and all unmarked strings get 2αˉ−b2\bar\alpha - b. The initial state ∣s⟩\ket s has the form with a=b=1/Na = b = 1/\sqrt N, and induction finishes the proof.

Try it yourself in the numerical example below. Press the two instructions one at a time and watch the dashed average line.

Intuition — why the marked amplitude grows

Right after the phase flip, the marked amplitude sits at about −a-a while the average is still close to bb. It is therefore about a+ba + b below the average, and reflecting puts it about a+ba + b above it. With NN large and aa small, each round adds roughly 2b≈2/N2b \approx 2/\sqrt N to the marked amplitude, which is Lecture 9's 1,3,5,7,…1, 3, 5, 7, \dots in course units. But each round also lowers the average a little, so the gains shrink. Eventually the average becomes negative and the marked amplitude starts to fall. The geometric view explains both effects at once.

3.5The Geometric View

By Lemma: Two numbers suffice, the NN-dimensional state only ever moves in a two-dimensional plane. Choosing good coordinates in that plane turns Grover's algorithm into a rotation, and rotations are easy to iterate.

Definition — The Grover plane

Assume 1≤t≤N−11 \le t \le N-1. Define the unit vectors

∣G⟩=1t∑x∈M∣x⟩,∣B⟩=1N−t∑x∉M∣x⟩,\ket{G} = \frac{1}{\sqrt t}\sum_{x\in M}\ket x, \qquad \ket{B} = \frac{1}{\sqrt{N-t}}\sum_{x\notin M}\ket x ,

the uniform superpositions over the good (marked) and bad (unmarked) strings. They are orthogonal, and span a plane PP. Let θ∈(0,π/2)\theta \in (0, \pi/2) be the angle with sin⁡θ=t/N\sin\theta = \sqrt{t/N}. For an angle φ\varphi, write ∣φ⟩=cos⁡φ ∣B⟩+sin⁡φ ∣G⟩\ket{\varphi} = \cos\varphi\,\ket B + \sin\varphi\,\ket G for the unit vector in PP at angle φ\varphi, measured from ∣B⟩\ket B towards ∣G⟩\ket G.

A state with amplitudes (a,b)(a, b) as in Lemma: Two numbers suffice is at ∣G⟩+bN−t ∣B⟩a\sqrt t\,\ket G + b\sqrt{N-t}\,\ket B, a vector in PP. In particular the starting state is

∣s⟩=tN ∣G⟩+N−tN ∣B⟩=sin⁡θ ∣G⟩+cos⁡θ ∣B⟩=∣θ⟩.\ket s = \sqrt{\tfrac tN}\,\ket G + \sqrt{\tfrac{N-t}{N}}\,\ket B = \sin\theta\,\ket G + \cos\theta\,\ket B = \ket{\theta} .

The probability that "extract all" prints a marked string, from the state ∣φ⟩\ket\varphi, is the total squared amplitude on marked strings, namely sin⁡2φ\sin^2\varphi. So the goal is to turn the angle from θ\theta (tiny when t≪Nt \ll N) to about π/2\pi/2.

Lemma — The phase flip is a mirror

On PP, OfO_f is the reflection across the line through ∣B⟩\ket B: Of∣φ⟩=∣−φ⟩O_f\ket\varphi = \ket{-\varphi}.

OfO_f negates every marked basic state, so Of∣G⟩=−∣G⟩O_f\ket G = -\ket G and Of∣B⟩=∣B⟩O_f\ket B = \ket B. Hence Of(cos⁡φ∣B⟩+sin⁡φ∣G⟩)=cos⁡φ∣B⟩−sin⁡φ∣G⟩=∣−φ⟩O_f(\cos\varphi\ket B + \sin\varphi\ket G) = \cos\varphi\ket B - \sin\varphi\ket G = \ket{-\varphi}.

Lemma — ReflectAcrossAverage is a mirror

DD maps PP to itself, and on PP it is the reflection across the line through ∣s⟩=∣θ⟩\ket s = \ket\theta: D∣φ⟩=∣2θ−φ⟩D\ket\varphi = \ket{2\theta - \varphi}.

By Lemma: ReflectAcrossAverage is a reflection, DD fixes ∣θ⟩=∣s⟩\ket\theta = \ket s and negates everything orthogonal to ∣s⟩\ket s; in particular it negates ∣θ+π/2⟩\ket{\theta + \pi/2}, which lies in PP and is orthogonal to ∣θ⟩\ket\theta. Write ∣φ⟩=cos⁡(φ−θ)∣θ⟩+sin⁡(φ−θ)∣θ+π/2⟩\ket\varphi = \cos(\varphi-\theta)\ket\theta + \sin(\varphi - \theta)\ket{\theta+\pi/2} (a rotation of coordinates by θ\theta). Applying DD gives cos⁡(φ−θ)∣θ⟩−sin⁡(φ−θ)∣θ+π/2⟩\cos(\varphi-\theta)\ket\theta - \sin(\varphi-\theta)\ket{\theta+\pi/2}, the vector at angle θ−(φ−θ)=2θ−φ\theta - (\varphi - \theta) = 2\theta - \varphi.

Lemma — Two mirrors make a rotation

In a plane, let RβR_\beta be the reflection across the line at angle β\beta, so Rβ∣φ⟩=∣2β−φ⟩R_\beta\ket\varphi = \ket{2\beta - \varphi}. Then RβRγR_\beta R_\gamma is the rotation by 2(β−γ)2(\beta - \gamma): it sends ∣φ⟩\ket\varphi to ∣φ+2(β−γ)⟩\ket{\varphi + 2(\beta - \gamma)}.

RβRγ∣φ⟩=Rβ∣2γ−φ⟩=∣2β−2γ+φ⟩R_\beta R_\gamma \ket\varphi = R_\beta\ket{2\gamma - \varphi} = \ket{2\beta - 2\gamma + \varphi}. (The formula Rβ∣φ⟩=∣2β−φ⟩R_\beta\ket\varphi = \ket{2\beta-\varphi} is the computation in the proof of Lemma: ReflectAcrossAverage is a mirror with θ\theta replaced by β\beta.)

Roadmap

The oracle is the mirror at angle 00 (Lemma: The phase flip is a mirror) and ReflectAcrossAverage is the mirror at angle θ\theta (Lemma: ReflectAcrossAverage is a mirror). By Lemma: Two mirrors make a rotation, one Grover iteration DOf=RθR0DO_f = R_\theta R_0 is a rotation by 2θ2\theta. Starting from angle θ\theta, we simply add 2θ2\theta per round.

Theorem — Grover's algorithm is a rotation

Let 1≤t≤N−11 \le t \le N - 1 and sin⁡θ=t/N\sin\theta = \sqrt{t/N}. After kk iterations the state is

(DOf)k∣s⟩  =  sin⁡((2k+1)θ) ∣G⟩+cos⁡((2k+1)θ) ∣B⟩,(DO_f)^k\ket s \;=\; \sin\big((2k+1)\theta\big)\,\ket G + \cos\big((2k+1)\theta\big)\,\ket B ,

so "extract all" prints a marked string with probability exactly sin⁡2((2k+1)θ)\sin^2\big((2k+1)\theta\big), and then each marked string is equally likely.

Induction on kk. For k=0k = 0 the state is ∣s⟩=∣θ⟩\ket s = \ket\theta. If after kk iterations the state is ∣(2k+1)θ⟩\ket{(2k+1)\theta}, then one more iteration gives RθR0∣(2k+1)θ⟩=∣(2k+1)θ+2θ⟩=∣(2k+3)θ⟩R_\theta R_0\ket{(2k+1)\theta} = \ket{(2k+1)\theta + 2\theta} = \ket{(2k+3)\theta} by the three lemmas. The probability statement is the remark after Definition: The Grover plane, and the last claim holds because all marked strings share one amplitude.

Remark — Back to Lecture 9

With one marked string, the amplitude on ∣x∗⟩\ket{x^*} in course units is Nsin⁡((2k+1)θ)\sqrt N \sin((2k+1)\theta), and θ=arcsin⁡(1/N)≈1/N\theta = \arcsin(1/\sqrt N) \approx 1/\sqrt N. While (2k+1)θ(2k+1)\theta is small, sin⁡((2k+1)θ)≈(2k+1)θ\sin((2k+1)\theta) \approx (2k+1)\theta, so the amplitude is about N⋅(2k+1)/N=2k+1\sqrt N\cdot(2k+1)/\sqrt N = 2k+1. That is exactly Lecture 9's "basically 1,3,5,7,…1, 3, 5, 7, \dots". The word "basically" was the small-angle approximation sin⁡y≈y\sin y \approx y, which breaks down when the angle nears π/2\pi/2: the sine curve flattens, and past π/2\pi/2 it decreases.

3.7Query Complexity of Search

Theorem: Grover's algorithm is a rotation says the success probability is sin⁡2((2k+1)θ)\sin^2((2k+1)\theta). To maximize it we want (2k+1)θ(2k+1)\theta as close to π/2\pi/2 as an integer kk allows, so k≈π4θ−12k \approx \frac{\pi}{4\theta} - \frac12. Taking the floor of π/(4θ)\pi/(4\theta) is a clean choice that never overshoots by more than one step.

Theorem — Grover search

Let 1≤t≤N−11 \le t \le N-1 be known, let sin⁡θ=t/N\sin\theta = \sqrt{t/N}, and run Grover's algorithm with k∗=⌊π/(4θ)⌋k^* = \lfloor \pi/(4\theta)\rfloor iterations. Then it outputs a marked string with probability at least 1−t/N1 - t/N, using

k∗  ≤  π4Nt  =  O ⁣(N/t) queries.k^* \;\le\; \frac{\pi}{4}\sqrt{\frac{N}{t}} \;=\; O\!\left(\sqrt{N/t}\right) \text{ queries.}

By definition of the floor, π4θ−1<k∗≤π4θ\frac{\pi}{4\theta} - 1 \lt k^* \le \frac{\pi}{4\theta}. Multiplying by 2θ2\theta and adding θ\theta:

3Part II — The complexity-theory perspective

We define BQP, show how Grover speeds up NP witness search, prove the BBBV Ω(√N) lower bound, and explain the limits of relativizing arguments.

4.1Introduction

Part I showed that a quantum computer can search NN possibilities with about π4N\frac\pi4\sqrt N evaluations of ff, where any classical algorithm needs about NN. This part asks what that means for complexity theory, along three lines.

  1. Classes. Where does efficient quantum computation sit among the classes from this course? We define BQP\BQP, place it between BPP\BPP and PSPACE\PSPACE, and turn Grover's algorithm into a statement about NP\NP: every NP\NP problem with witnesses of length mm can be solved in quantum time about 2m/22^{m/2}.
  2. A lower bound we can prove. A recurring theme of the course is that lower bounds are hard: we cannot even show SAT∉P\text{SAT}\notin\Ptime, which is why the reductions lectures settle for conditional lower bounds. In the query model, however, we can prove one. The centerpiece of this part, Theorem: Bennett, Bernstein, Brassard, Vazirani, shows that every quantum algorithm needs Ω(N)\Omega(\sqrt N) queries for search, so Grover's algorithm is optimal.
  3. What it says about NP\NP versus BQP\BQP. The lower bound gives an oracle relative to which NP⊈BQP\NP\not\subseteq\BQP, strong evidence that quantum computers cannot solve NP\NP-complete problems by brute force. We also see why this kind of evidence can never become a proof, and what else is known about the place of BQP\BQP.
Roadmap — the lower bound

The proof of Theorem: Bennett, Bernstein, Brassard, Vazirani compares two runs of an arbitrary algorithm: one where a string xx is marked and one where nothing is. To answer correctly, the two final states must be far apart (Distances Between States). Swapping the oracle one query at a time shows the distance is at most the sum of what each query "sees" of xx (The Hybrid Argument). Since the algorithm's total attention is spread over NN strings, some xx gets very little of it (Query Magnitudes), and for that xx the runs stay close unless T=Ω(N)T = \Omega(\sqrt N).

4.2Quantum Computation as a Complexity Class

So far we counted queries. Complexity theory instead asks which languages have efficient algorithms. For randomized computation the course defined BPP\BPP: polynomial time, with error probability at most 1/31/3 on every input. The quantum analogue is defined the same way, with quantum programs in place of randomized ones.

Definition — BQP

A language LL is in BQP\BQP if there are a polynomial pp and a polynomial-time classical algorithm that, given 1n1^n, outputs a quantum program QnQ_n with at most p(n)p(n) instructions from the course's instruction set (new qubit, Hadamard, classical reversible instructions such as "if A and B then toggle C", "if A then minus", extract) such that for every x∈{0,1}nx\in\{0,1\}^n, when QnQ_n is run with its first nn qubits toggled to xx and a designated output qubit is extracted at the end,

  • if x∈Lx\in L, the output is 11 with probability at least 2/32/3;
  • if x∉Lx\notin L, the output is 11 with probability at most 1/31/3.

Two choices in this definition do not matter. As for BPP\BPP, the constant 2/32/3 can be replaced by 1−2−nc1 - 2^{-n^c} by running the program O(nc)O(n^c) times and taking the majority vote. And any universal instruction set gives the same class, because each can approximate the others efficiently [NC10].

Theorem — Where BQP sits
BPP  ⊆  BQP  ⊆  PP  ⊆  PSPACE.\BPP \;\subseteq\; \BQP \;\subseteq\; \PP \;\subseteq\; \PSPACE .

Here PP\PP is the class of languages decided by polynomial-time randomized algorithms that are correct with probability strictly greater than 1/21/2 (with no gap required).

BPP⊆BQP\BPP\subseteq\BQP. A BPP\BPP algorithm is a deterministic polynomial-time computation on its input and a string of random bits. A quantum program can produce a fair random bit with "new qubit, Hadamard, extract", and it can run any deterministic computation using classical reversible instructions (the same recipe the course used to turn classical code into "if ff then minus").

BQP⊆PSPACE\BQP\subseteq\PSPACE. Let QnQ_n act on mm qubits with instructions U1,…,UTU_1,\dots,U_T, all qubits created at the start, and extraction at the end. Write αj(z)\alpha_j(z) for the amplitude of ∣z⟩\ket z after jj instructions. Then

αj(z)=∑y∈{0,1}m⟨z∣Uj∣y⟩ αj−1(y),α0(z)=[z=0m].\alpha_j(z) = \sum_{y\in\{0,1\}^m} \bra z U_j \ket y\, \alpha_{j-1}(y), \qquad \alpha_0(z) = [z = 0^m] .

Every instruction touches at most three qubits and has at most two nonzero entries ⟨z∣Uj∣y⟩\bra z U_j\ket y for each zz (a Hadamard mixes two basic states, a classical reversible instruction permutes them, a phase flip multiplies by ±1\pm1), and these entries are easy to compute. So a recursive procedure Amp(j,z)\mathrm{Amp}(j, z) that calls Amp(j−1,y)\mathrm{Amp}(j-1,y) for the at most two relevant yy computes αT(z)\alpha_T(z) exactly, as an integer divided by a power of 2\sqrt2. The recursion has depth TT and each level stores O(m+T)O(m + T) bits, so the space is polynomial (the time is exponential, which is fine). Finally, loop over all zz whose output qubit is 11, add up αT(z)2\alpha_T(z)^2 reusing the same space, and accept if the sum exceeds 1/21/2.

BQP⊆PP\BQP\subseteq\PP and PP⊆PSPACE\PP\subseteq\PSPACE. The first is the same "sum over paths" idea, sharpened: the acceptance probability minus 1/21/2 is, up to scaling, a difference between two numbers of accepting paths of polynomial-time computations, and deciding the sign of such a difference is exactly what PP\PP can do [ADH97]. The second holds because a polynomial-space machine can count the accepting random strings of a PP\PP algorithm one by one.

Omitted — BQP\subseteq\PP

We only sketched this inclusion; the full proof is in [ADH97]. The inclusion BPP⊆BQP⊆PSPACE\BPP\subseteq\BQP\subseteq\PSPACE is due to Bernstein and Vazirani [BV97].

The known inclusions are BPP ⊆ BQP ⊆ PP ⊆ PSPACE. The exact relationship between NP and BQP is open. Grover gives a quadratic black-box speedup, not a polynomial-time algorithm for general SAT.

Grover's algorithm for NP\NP

An NP\NP language LL has a polynomial-time verifier VV: x∈Lx\in L if and only if V(x,w)=1V(x,w) = 1 for some witness w∈{0,1}mw\in\{0,1\}^m, with mm polynomial in ∣x∣\abs x. Deciding LL is a search for a marked ww, where fx(w)=V(x,w)f_x(w) = V(x,w), so Part I applies with N=2mN = 2^m. One wrinkle: we do not know the number tt of witnesses, and Remark: More is not better warned that Grover's algorithm needs to know when to stop. The fix is to stop at a random time.

Theorem — Quantum search for NP

Let L∈NPL\in\NP with verifier VV and witness length m=m(n)m = m(n). There is a quantum algorithm that never accepts x∉Lx\notin L, accepts every x∈Lx\in L with probability at least 2/32/3, and runs in time 2m/2⋅poly(n)2^{m/2}\cdot\poly(n).

Let N=2m≥2N = 2^m \ge 2 (if m=0m = 0 there is nothing to search) and K=⌈N⌉K = \lceil\sqrt N\rceil. Theorem: Quantum search for NP is a genuine speedup, yet still exponential: for SAT on nn variables it gives time about 2n/22^{n/2}, not poly(n)\poly(n). So it does not put NP\NP inside BQP\BQP. Is NP⊆BQP\NP\subseteq\BQP? Nobody knows, and since P⊆BQP\Ptime\subseteq\BQP, a proof that NP⊈BQP\NP\not\subseteq\BQP would in particular prove P≠NP\Ptime\ne\NP. What we can do is show that no algorithm that uses ff only as a black box beats Grover. That is the next four sections.

4.3The General Query Model

To prove that every algorithm needs many queries, we first fix what "every algorithm" means. We allow anything at all between queries, at no cost.

Definition — T-query algorithm

A TT-query algorithm works on a query register of nn qubits, one control qubit and any number of workspace qubits, all starting at 00. It applies arbitrary unitaries U0,U1,…,UTU_0, U_1, \dots, U_T (any instructions not involving ff) interleaved with TT queries, then extracts a designated output qubit. Its final state on ff is

∣ψf⟩=UT Of UT−1 Of⋯U1 Of U0∣0⋯0⟩,\ket{\psi^f} = U_T\, O_f\, U_{T-1}\, O_f \cdots U_1\, O_f\, U_0 \ket{0\cdots0},

where the query OfO_f is "if control and f(query register)f(\text{query register}) then minus": it multiplies the amplitude of each basic state whose query register holds xx and whose control is 11 by (−1)f(x)(-1)^{f(x)}.

The control qubit makes this model slightly more general than Part I's (fix the control to 11 to recover "if ff then minus"), which only strengthens a lower bound. It also lets an algorithm read off f(x)f(x) for a known xx: put the control in the state 12(∣0⟩+∣1⟩)\frac{1}{\sqrt2}(\ket0+\ket1) with a Hadamard, query, and apply a Hadamard again; the control then reads f(x)f(x).

Definition — The OR problem

In the problem ORN\OR_N the algorithm must decide whether f:{0,1}n→{0,1}f:\{0,1\}^n\to\{0,1\} has at least one marked string. A TT-query algorithm decides ORN\OR_N with error at most 1/31/3 if for every ff its output equals OR(f)\OR(f) with probability at least 2/32/3.

Remark — Deciding is no harder than searching

A search algorithm with TT queries gives a decision algorithm with T+1T+1 queries: run it, then check its output xx with one more query as described above, and answer "marked" exactly when f(x)=1f(x) = 1. So a lower bound of cNc\sqrt N for ORN\OR_N is a lower bound of cN−1c\sqrt N - 1 for search.

Two oracles matter in the proof: the empty function f≡0f\equiv 0, whose query is the identity II, and the function fxf_x marking only xx, whose query we write OxO_x. Writing Πx\Pi_x for the projection onto basic states whose query register holds xx (whatever the other qubits hold), and Πx,1\Pi_{x,1} for those that also have control 11,

Ox=I−2 Πx,1,∑xΠx=I.O_x = I - 2\,\Pi_{x,1}, \qquad \sum_{x}\Pi_x = I .
Important — Why this is strong

The unitaries UjU_j are completely arbitrary: they may have exponential size and may encode any clever idea. The only restriction is that ff is used as a black box. So a lower bound in this model rules out every algorithm that does not look inside ff.

4.4Distances Between States

We need three facts about vectors in RD\R^D (or CD\mathbb C^D) that go slightly beyond the course; all are standard. The length is ∥v∥=∑ivi2\norm{v} = \sqrt{\sum_i v_i^2}. The triangle inequality says ∥u+v∥≤∥u∥+∥v∥\norm{u + v}\le\norm u + \norm v. The Cauchy–Schwarz inequality says ∣∑iuivi∣≤∥u∥ ∥v∥\abs{\sum_i u_i v_i}\le\norm u\,\norm v; for nonnegative numbers a1,…,aTa_1,\dots,a_T it gives in particular ∑iai≤T∑iai2\sum_i a_i \le \sqrt{T}\sqrt{\sum_i a_i^2} (take u=au = a and vv the all-ones vector).

Definition — Distance

The distance between states ∣ψ⟩\ket\psi and ∣φ⟩\ket\varphi is ∥∣ψ⟩−∣φ⟩∥\norm{\ket\psi - \ket\varphi}.

Lemma — Unitaries preserve distance

For every unitary UU: ∥U∣ψ⟩−U∣φ⟩∥=∥∣ψ⟩−∣φ⟩∥\norm{U\ket\psi - U\ket\varphi} = \norm{\ket\psi - \ket\varphi}.

U∣ψ⟩−U∣φ⟩=U(∣ψ⟩−∣φ⟩)U\ket\psi - U\ket\varphi = U(\ket\psi - \ket\varphi) by linearity, and UU preserves lengths (Lecture 7's "unitary": total squared amplitude is unchanged).

Lemma — Close states give close outcomes

Let ∣ψ⟩,∣φ⟩\ket\psi,\ket\varphi be states with ∥∣ψ⟩−∣φ⟩∥≤ε\norm{\ket\psi - \ket\varphi}\le\varepsilon. For every set SS of outcomes of "extract all", the probabilities of SS under ∣ψ⟩\ket\psi and under ∣φ⟩\ket\varphi differ by at most ε\varepsilon.

Let dz=ψz2−φz2d_z = \psi_z^2 - \varphi_z^2 be the difference in the probability of outcome zz. By Cauchy–Schwarz and the triangle inequality,

∑z∣dz∣=∑z∣ψz−φz∣ ∣ψz+φz∣≤∥ψ−φ∥ ∥ψ+φ∥≤ε⋅2.\sum_z \abs{d_z} = \sum_z \abs{\psi_z - \varphi_z}\,\abs{\psi_z + \varphi_z} \le \norm{\psi - \varphi}\,\norm{\psi + \varphi} \le \varepsilon\cdot 2 .

Both distributions sum to 11, so ∑zdz=0\sum_z d_z = 0 and ∑z∈Sdz=−∑z∉Sdz\sum_{z\in S} d_z = -\sum_{z\notin S}d_z. Hence 2∣∑z∈Sdz∣≤∑z∣dz∣≤2ε2\abs{\sum_{z\in S}d_z} \le \sum_z\abs{d_z}\le 2\varepsilon.

Intuition

A measurement cannot distinguish states that are close. So to prove an algorithm must make many queries, it suffices to show that with few queries, the final states on two inputs with different answers remain close. Distance is the right currency because unitaries never change it: only queries can create it.

4.5The Hybrid Argument

Fix a TT-query algorithm and a string xx. We compare the run on fxf_x, ending in ∣ψx⟩\ket{\psi^x}, with the run on the empty function, ending in ∣ψ∅⟩\ket{\psi^\emptyset}. The two runs use different oracles at all TT queries, which is hard to analyze at once. Instead, we change the oracle one query at a time and charge each change separately.

Definition — Hybrid runs

For 1≤t≤T1\le t\le T, let ∣φt⟩=Ut−1⋯U1U0∣0⋯0⟩\ket{\varphi_t} = U_{t-1}\cdots U_1U_0\ket{0\cdots0} be the state of the empty run just before its tt-th query (in the empty run every query is II). For 0≤j≤T0\le j\le T, the hybrid ∣Hj⟩\ket{H_j} is the final state of the run that uses II for the first jj queries and OxO_x for the remaining T−jT-j. Thus ∣H0⟩=∣ψx⟩\ket{H_0} = \ket{\psi^x} and ∣HT⟩=∣ψ∅⟩\ket{H_T} = \ket{\psi^\emptyset}.

Lemma — Hybrid argument
∥∣ψx⟩−∣ψ∅⟩∥  ≤  ∑t=1T∥(Ox−I)∣φt⟩∥.\norm{\ket{\psi^x} - \ket{\psi^\emptyset}} \;\le\; \sum_{t=1}^T \norm{(O_x - I)\ket{\varphi_t}} .

Consecutive hybrids ∣Ht−1⟩\ket{H_{t-1}} and ∣Ht⟩\ket{H_t} agree on the first t−1t-1 queries (both use II), so both reach ∣φt⟩\ket{\varphi_t} just before query tt. They also agree after query tt (both use OxO_x from then on), so with Vt=UTOxUT−1⋯OxUtV_t = U_T O_x U_{T-1}\cdots O_x U_t,

∣Ht−1⟩−∣Ht⟩=Vt Ox∣φt⟩−Vt∣φt⟩=Vt (Ox−I)∣φt⟩.\ket{H_{t-1}} - \ket{H_t} = V_t\,O_x\ket{\varphi_t} - V_t\ket{\varphi_t} = V_t\,(O_x - I)\ket{\varphi_t}.

By Lemma: Unitaries preserve distance, ∥∣Ht−1⟩−∣Ht⟩∥=∥(Ox−I)∣φt⟩∥\norm{\ket{H_{t-1}} - \ket{H_t}} = \norm{(O_x - I)\ket{\varphi_t}}. Now write ∣ψx⟩−∣ψ∅⟩=∑t=1T(∣Ht−1⟩−∣Ht⟩)\ket{\psi^x} - \ket{\psi^\emptyset} = \sum_{t=1}^T\big(\ket{H_{t-1}} - \ket{H_t}\big) (the sum telescopes) and apply the triangle inequality.

Intuition

Notice that only the states ∣φt⟩\ket{\varphi_t} of the empty run appear on the right. They do not depend on xx at all. So one fixed sequence of states controls how far every fxf_x-run can drift, and this is what lets us average over xx in the next section.

4.6Query Magnitudes

Definition — Query magnitude

The query magnitude of xx at query tt is qx(t)=∥Πx∣φt⟩∥2q_x(t) = \norm{\Pi_x\ket{\varphi_t}}^2: the probability of seeing xx if the query register were measured just before the tt-th query of the empty run. The total query magnitude of xx is Qx=∑t=1Tqx(t)Q_x = \sum_{t=1}^T q_x(t).

Lemma — Total attention is T

For every tt, ∑xqx(t)=1\sum_x q_x(t) = 1. Hence ∑xQx=T\sum_x Q_x = T.

The projections Πx\Pi_x pick out disjoint sets of basic states that together cover all of them, so ∑x∥Πx∣φt⟩∥2=∥∣φt⟩∥2=1\sum_x\norm{\Pi_x\ket{\varphi_t}}^2 = \norm{\ket{\varphi_t}}^2 = 1. Summing over t=1,…,Tt = 1,\dots,T gives TT.

Corollary — A neglected string

Some xx has Qx≤T/NQ_x\le T/N.

The NN numbers QxQ_x sum to TT, so their minimum is at most their average T/NT/N.

Claim — One query moves the state by an amplitude

∥(Ox−I)∣φt⟩∥≤2qx(t)\norm{(O_x - I)\ket{\varphi_t}} \le 2\sqrt{q_x(t)}.

Ox−I=−2 Πx,1O_x - I = -2\,\Pi_{x,1}, and projecting onto fewer basic states can only shorten a vector, so ∥(Ox−I)∣φt⟩∥=2∥Πx,1∣φt⟩∥≤2∥Πx∣φt⟩∥=2qx(t)\norm{(O_x - I)\ket{\varphi_t}} = 2\norm{\Pi_{x,1}\ket{\varphi_t}}\le 2\norm{\Pi_x\ket{\varphi_t}} = 2\sqrt{q_x(t)}.

Intuition — where the square root comes from

Classically, an algorithm with fewer than NN queries never looks at some string, and therefore cannot know whether that string is marked. Quantumly, an algorithm can look at every string "a little" at each query. But Lemma: Total attention is T says the total amount of looking is still exactly TT, measured in probability. The catch is that a query changes the state by an amplitude, the square root of that probability (Claim: One query moves the state by an amplitude). A string that gets probability T/NT/N in total, spread over TT queries, gets amplitude about 1/N\sqrt{1/N} per query, and TT such changes add up to only T/NT/\sqrt N. The gap between probabilities and amplitudes is precisely the gap between NN and N\sqrt N.

4.7The Lower Bound

Theorem — Bennett, Bernstein, Brassard, Vazirani

Every quantum algorithm that decides ORN\OR_N with error at most 1/31/3 makes at least N/6\sqrt N/6 queries. Consequently every quantum search algorithm that succeeds with probability at least 2/32/3 makes at least N/6−1\sqrt N/6 - 1 queries.

Roadmap

Pick the neglected string xx of Corollary: A neglected string. Bound how far the fxf_x-run drifts from the empty run using Lemma: Hybrid argument, Claim: One query moves the state by an amplitude and Cauchy–Schwarz: at most 2T/N2T/\sqrt N. Correctness forces a drift of at least 1/31/3 by Lemma: Close states give close outcomes.

Let the algorithm make TT queries, and choose xx with Qx≤T/NQ_x\le T/N (Corollary: A neglected string).

Upper bound on the drift. By Lemma: Hybrid argument and Claim: One query moves the state by an amplitude, then Cauchy–Schwarz with at=qx(t)a_t = \sqrt{q_x(t)},

∥∣ψx⟩−∣ψ∅⟩∥≤2∑t=1Tqx(t)  ≤  2T∑t=1Tqx(t)=2T Qx  ≤  2T⋅TN  =  2TN.\begin{aligned}\norm{\ket{\psi^x} - \ket{\psi^\emptyset}} &\le 2\sum_{t=1}^T\sqrt{q_x(t)} \;\le\; 2\sqrt T\sqrt{\sum_{t=1}^T q_x(t)} \\ &= 2\sqrt{T\,Q_x} \;\le\; 2\sqrt{T\cdot\frac TN} \;=\; \frac{2T}{\sqrt N}.\end{aligned}

Lower bound on the drift. On the empty function the correct answer is 00, so the output is 11 with probability at most 1/31/3. On fxf_x the correct answer is 11, so the output is 11 with probability at least 2/32/3. These two probabilities of the same event differ by at least 1/31/3, so by Lemma: Close states give close outcomes, ∥∣ψx⟩−∣ψ∅⟩∥≥1/3\norm{\ket{\psi^x}-\ket{\psi^\emptyset}}\ge 1/3.

Combining, 1/3≤2T/N1/3\le 2T/\sqrt N, that is, T≥N/6T\ge\sqrt N/6. The statement about search follows from Remark: Deciding is no harder than searching.

It is worth seeing the proof in action on Grover's algorithm itself. In the empty run, ReflectAcrossAverage fixes ∣s⟩\ket s, so ∣φt⟩=∣s⟩\ket{\varphi_t} = \ket s for every tt and every query magnitude is exactly 1/N1/N: Grover spreads its attention perfectly evenly. The bound then says the two runs end at distance at most 2T/N2T/\sqrt N. In fact, by Theorem: Grover's algorithm is a rotation the fxf_x-run ends at angle (2T+1)θ(2T+1)\theta and the empty run stays at angle θ\theta, so their distance is 2sin⁡(Tθ)≈2T/N2\sin(T\theta)\approx 2T/\sqrt N for small TT.

Remark — Tightness

The lower bound matches Grover’s Θ(√N) upper bound. In the oracle model, this proves that the quadratic speedup is optimal up to constants.

Remark — Only some strings variable

The proof never used that the oracle is defined on all of {0,1}n\{0,1\}^n. If ff is fixed outside a set SS of NN strings and the algorithm must decide whether some string of SS is marked, the same argument works with Πx\Pi_x for x∈Sx\in S only: their magnitudes still sum to at most 11 per query. Queries outside SS are fixed unitaries and can be absorbed into the UjU_j. We use this in the oracle construction below.

4.8Consequences: Oracles and NP\NP versus BQP\BQP

Corollary — Black-box SAT

Every quantum algorithm that decides whether a Boolean function on nn variables is satisfiable, using the function only through queries, needs at least 2n/2/62^{n/2}/6 queries. In particular the algorithm of Theorem: Quantum search for NP is optimal among black-box methods, up to a constant factor.

This is Theorem: Bennett, Bernstein, Brassard, Vazirani with N=2nN = 2^n.

This does not rule out fast quantum algorithms for SAT that look inside the formula, just as classical algorithms do. Schöning's randomized algorithm for 3-SAT runs in time about (4/3)n(4/3)^n, already faster than 2n/2≈1.414n2^{n/2}\approx 1.414^n [Sch99]; amplitude amplification (Remark: Amplitude amplification) speeds it up to about (4/3)n/2≈1.155n(4/3)^{n/2}\approx 1.155^n. Grover's speedup is a layer that can sit on top of clever classical algorithms, not a replacement for them.

To turn the query lower bound into a statement about classes, we use oracles, as in the course's study of relativization. For a language AA, BQPA\BQP^A is defined like BQP\BQP but with an extra instruction, "if control and X1⋯Xℓ∈AX_1\cdots X_\ell\in A then minus", for every register length ℓ\ell; NPA\NP^A is defined from oracle machines as usual.

Theorem — An oracle separating NP from BQP

There is a language AA such that NPA⊈BQPA\NP^A\not\subseteq\BQP^A.

Let LA={1n:A contains some string of length n}L_A = \{1^n : A \text{ contains some string of length } n\}. For every AA, LA∈NPAL_A\in\NP^A: guess a string xx of length nn and check x∈Ax\in A with one query. We construct AA so that LA∉BQPAL_A\notin\BQP^A.

Enumerate pairs (Gi,pi)(G_i, p_i) where GiG_i is a polynomial-time program generator and pi(n)=ni+ip_i(n) = n^i + i; every BQPA\BQP^A language is decided by some GiG_i whose programs have at most pi(n)p_i(n) instructions. We build AA in stages, deciding at stage ii the membership of all strings of lengths up to some bound ℓi\ell_i, starting with ℓ0=0\ell_0 = 0.

Stage ii. Choose ni>ℓi−1n_i\gt\ell_{i-1} so large that pi(ni)<2ni/6p_i(n_i)\lt\sqrt{2^{n_i}}/6. Put no strings of lengths in (ℓi−1,pi(ni)](\ell_{i-1}, p_i(n_i)] other than nin_i into AA. Now consider the program Q=Gi(1ni)Q = G_i(1^{n_i}) on input 1ni1^{n_i}. It has at most pi(ni)p_i(n_i) instructions, so it makes at most pi(ni)p_i(n_i) queries, each to strings of length at most pi(ni)p_i(n_i). All those lengths are already decided except nin_i, so QQ is a query algorithm for OR\OR on the N=2niN = 2^{n_i} strings of length nin_i, in the sense of Remark: Only some strings variable. Since it makes fewer than N/6\sqrt N/6 queries, Theorem: Bennett, Bernstein, Brassard, Vazirani says it does not decide ORN\OR_N with error at most 1/31/3: either with no string of length nin_i in AA, or with a single such string xx, it gives the wrong answer with probability more than 1/31/3. Fix AA at length nin_i accordingly, and set ℓi=pi(ni)\ell_i = p_i(n_i).

Later stages only decide strings longer than ℓi\ell_i, so the run of QQ is never changed. Thus for every ii, the program family GiG_i errs with probability more than 1/31/3 on 1ni1^{n_i}, so no family decides LAL_A with bounded error, and LA∉BQPAL_A\notin\BQP^A.

Omitted — Random oracles

Bennett, Bernstein, Brassard and Vazirani prove more: for a uniformly random oracle AA, with probability 11, NPA\NP^A is not even contained in quantum time o(2n/2)o(2^{n/2}) [BBBV97]. We omit that proof; it combines the same lower bound with a probabilistic argument over the choice of AA.

How much does Theorem: An oracle separating NP from BQP tell us about the real (unrelativized) question? The course met the same situation for P\Ptime versus NP\NP: Baker, Gill and Solovay found oracles relative to which P=NP\Ptime = \NP and others relative to which P≠NP\Ptime\ne\NP [BGS75], so no proof technique that works equally well relative to every oracle can settle it. The same happens here.

Proposition — An oracle in the other direction

If BB is PSPACE\PSPACE-complete, then NPB⊆BQPB\NP^B\subseteq\BQP^B.

A polynomial-space machine can answer BB-queries itself, so NPB⊆PSPACEB=PSPACE\NP^B\subseteq\PSPACE^B = \PSPACE. Every PSPACE\PSPACE language reduces to BB, so PSPACE⊆PB\PSPACE\subseteq\Ptime^B. And PB⊆BQPB\Ptime^B\subseteq\BQP^B, because a quantum program can run a deterministic oracle computation reversibly. Chaining, NPB⊆PSPACE⊆PB⊆BQPB\NP^B\subseteq\PSPACE\subseteq\Ptime^B\subseteq\BQP^B.

The key logical distinction is query complexity versus time complexity. The proof rules out improved black-box quantum search even with free computation between queries. It does not show an exponential time lower bound for an explicitly described SAT formula: an algorithm that exploits the formula's internal structure need not behave like an oracle algorithm.

Important — What the oracle results do and do not show

Together, Theorem: An oracle separating NP from BQP and Proposition: An oracle in the other direction show that the question "is NP⊆BQP\NP\subseteq\BQP?" cannot be resolved by relativizing arguments. They do not show that NP⊈BQP\NP\not\subseteq\BQP. What they do show is that any quantum algorithm for an NP\NP-complete problem would have to exploit the structure of the problem, since black-box search can only be sped up quadratically. Most complexity theorists take this as strong evidence that NP⊈BQP\NP\not\subseteq\BQP.

4.9Beyond NP\NP: Where Might BQP\BQP Sit?

This section is a short survey; the results are cited, not proved. Oracle results also point in the other direction, showing what quantum computers can do that classical ones cannot.

  • Quantum beats classical, relative to oracles. Bernstein and Vazirani gave an oracle problem solvable in BQP\BQP but not in BPP\BPP [BV97], built on the Hadamard-transform tricks of Lectures 7–8 (MysteryToggles is the one-level version). Simon made the gap exponential with an oracle problem about hidden periodicity [Sim97].
  • Structure gives big speedups. Simon's idea led to Shor's algorithm, which factors integers in polynomial time on a quantum computer [Sho97]. Factoring is in NP∩coNP\NP\cap\coNP and is not believed to be NP\NP-hard, so this is no contradiction with the evidence above: it exploits periodic structure that unstructured search lacks.
  • BQP\BQP versus the polynomial hierarchy. Raz and Tal constructed an oracle relative to which BQP⊈PH\BQP\not\subseteq\mathsf{PH} [RT22]: there are oracle problems a quantum computer solves efficiently that lie outside the entire polynomial hierarchy.

So relative to suitable oracles, neither of NP\NP and BQP\BQP contains the other: NPA⊈BQPA\NP^A\not\subseteq\BQP^A for the oracle of Theorem: An oracle separating NP from BQP, and BQPA′⊈NPA′\BQP^{A'}\not\subseteq\NP^{A'} for the Raz–Tal oracle A′A', since NP⊆PH\NP\subseteq\mathsf{PH}. Without oracles, all of these questions are open, and none can be settled by relativizing techniques alone.

Remark — Reading oracle results

An oracle separation is a statement about algorithms that treat part of their input as a black box. It identifies which kind of speedup is possible: Grover-type speedups for unstructured problems are at most quadratic, while exponential speedups need structure, like the periodicity in Simon's and Shor's problems.

4.10Other Lower-Bound Methods

The hybrid argument is the simplest route to the Ω(N)\Omega(\sqrt N) bound, but not the only one. Both methods below are surveyed without proof.

  • The polynomial method. If an algorithm makes TT queries to ff, its acceptance probability is a real polynomial of degree at most 2T2T in the NN bits f(x)f(x) [BBCMW01]. An algorithm deciding ORN\OR_N with error 1/31/3 therefore yields a polynomial that approximates ORN\OR_N within 1/31/3 everywhere, and every such polynomial has degree Ω(N)\Omega(\sqrt N) [NS94]. This gives the same bound, and the method extends to many other functions.
  • The adversary method. Ambainis's method tracks how much a single query can increase the distinguishability of carefully chosen pairs of inputs [Amb02]. It generalizes the hybrid argument and gives tight bounds for many problems where the polynomial method does not.

4.11Summary

Note
  1. BQP\BQP is sandwiched. BPP⊆BQP⊆PP⊆PSPACE\BPP\subseteq\BQP\subseteq\PP\subseteq\PSPACE: quantum computers are at most "polynomial-space powerful".
  2. Grover for NP\NP. Any NP\NP problem with mm-bit witnesses can be solved in quantum time 2m/2poly(n)2^{m/2}\poly(n), a quadratic speedup over brute force that still does not put NP\NP in BQP\BQP.
  3. A proven lower bound. In the black-box model, Ω(N)\Omega(\sqrt N) queries are necessary. The proof: total query attention is TT, but queries change the state only by amplitudes, its square roots.
  4. Evidence, not proof. There is an oracle with NPA⊈BQPA\NP^A\not\subseteq\BQP^A and another with NPB⊆BQPB\NP^B\subseteq\BQP^B, so relativizing techniques cannot decide whether quantum computers solve NP\NP-complete problems efficiently.
  5. Structure is everything. Unstructured search allows only a quadratic speedup; exponential speedups, like Shor's, need structure.

Across both parts: search needs Θ(N)\Theta(N) queries classically and Θ(N)\Theta(\sqrt N) quantumly. Grover's algorithm achieves the upper bound with two mirrors, and the hybrid argument shows the mirrors cannot be beaten.
