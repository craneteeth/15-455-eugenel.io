Grover's Algorithm

Eugene Lee · CS455, Fall 2026Quantum search, its optimality, and the limits of black-box computation

Introduction

Suppose we are given a Boolean function f:{0,1}n→{0,1}f:\{0,1\}^n\to\{0,1\} and want to find an input xx for which f(x)=1f(x)=1. If we know nothing about the function besides the results of evaluating it, the obvious classical strategy is to test candidate inputs. With N=2nN=2^n possibilities, this takes Θ(N)\Theta(N) evaluations in the worst case. Grover's algorithm finds a marked input with bounded error after only O(N)O(\sqrt N) evaluations on a quantum computer. It also comes with a matching query lower bound: no quantum algorithm can asymptotically improve the number of black-box evaluations.

These notes develop both sides of the statement. We begin with the quantum mechanics needed to understand the algorithm, prove its exact success probability, and then prove the matching lower bound. The last part puts the result in context: why it gives a speedup for SAT, why this does not imply that SAT is in BQP, and exactly what an oracle lower bound can tell us.

Background assumed. We use the standard CS455 notions of P, NP, BPP, polynomial-time reductions, and the NP-completeness of SAT. No prior quantum computing is assumed: qubits, bra-ket notation, gates, and the necessary linear algebra are introduced below. We define quantum oracle access and relativization at the point where they are needed. In the course's reductions notes, the central obstacle is proving unconditional lower bounds for explicit problems; the query model gives a setting where a sharp unconditional bound can be proved. Unstructured Search

Let X\mathcal{X} be a set of NN candidate inputs. We are given oracle access to a function f:X→{0,1}f:\mathcal{X}\to\{0,1\}. We can ask for f(x)f(x) for a chosen xx, but are not told a representation of ff that reveals patterns among its values. An element is marked if f(x)=1f(x)=1.

Definition 1 (Search problem).

Given oracle access to f:{0,1}n→{0,1}f:\{0,1\}^n\to\{0,1\}, find an xx with f(x)=1f(x)=1, if one exists. Write N=2nN=2^n for the number of candidates and M=∣{x:f(x)=1}∣M=|\{x:f(x)=1\}| for the number of marked candidates. The unique-search promise says M=1M=1.

The distinction between NN and nn is essential. A query bound of N\sqrt N is a quadratic improvement as a function of the search-space size, but N=2n/2\sqrt N=2^{n/2} is still exponential in the number of input bits.

Proposition 2 (Classical query complexity).

Under the unique-search promise, deterministic search requires Θ(N)\Theta(N) queries in the worst case. Randomized search with constant success probability also requires Ω(N)\Omega(N) queries.

Deterministic adversary. Answer 0 to each new query. With the promise of exactly one marked element, a deterministic search procedure cannot identify the marked location while at least two candidates remain unqueried: either location is consistent with the transcript. Therefore it needs at least N−1N-1 queries in the worst case; asking about N−1N-1 candidates is sufficient.

Randomized adversary. Choose the unique mark JJ uniformly from all NN locations, independently of the algorithm's coins. First fix those coins. On the hypothetical all-zero transcript, the deterministic query schedule visits at most QQ distinct locations. A uniformly chosen JJ lies on this schedule with probability at most Q/NQ/N. If the mark is absent from those addresses, the transcript is identical for every remaining candidate. The algorithm's final guess can correctly identify at most one of them. Consequently its total success probability, averaged over JJ, is at most

QN+(1−QN)1N−Q=Q+1N(Q<N).\frac{Q}{N}+\left(1-\frac{Q}{N}\right)\frac1{N-Q}=\frac{Q+1}{N}\quad(Q<N).

Average this inequality over the algorithm's random coins. If success is at least 2/32/3 for every marked location, its average is also at least 2/32/3, giving Q≥2N/3−1=Ω(N)Q\ge 2N/3-1=\Omega(N). This is the distributional-adversary proof of randomized query hardness. The argument concerns search with a unique mark; distinguishing zero from one mark similarly needs Ω(N)\Omega(N) classical queries.

We will compare the number of calls to the oracle rather than assume each call costs one elementary gate. The distinction matters when ff is given by a formula or program: evaluating ff may itself require computation.

Quantum Basics

Qubits, amplitudes, and measurement

A classical bit is either 0 or 1. A qubit is a unit vector in a two-dimensional complex vector space, customarily written

∣ψ⟩=α∣0⟩+β∣1⟩,α,β∈C,∣α∣2+∣β∣2=1.|\psi\rangle=\alpha|0\rangle+\beta|1\rangle,\qquad \alpha,\beta\in\mathbb C,\quad |\alpha|^2+|\beta|^2=1.

Bra-ket notation. A ket ∣v⟩|v\rangle is a column vector. Its bra ⟨v∣\langle v| is the conjugate-transpose row vector. The expression ⟨u∣v⟩\langle u|v\rangle is an inner product (a scalar), whereas ∣v⟩⟨v∣|v\rangle\langle v| is an outer product (a matrix). If ∣v⟩|v\rangle is normalized, that matrix projects onto the direction ∣v⟩|v\rangle. Thus 2∣s⟩⟨s∣−I2|s\rangle\langle s|-I is an ordinary matrix operation, not a special new kind of multiplication.

The basis vectors are ∣0⟩=(1,0)T|0\rangle=(1,0)^\mathsf{T} and ∣1⟩=(0,1)T|1\rangle=(0,1)^\mathsf{T}. The numbers α\alpha and β\beta are amplitudes. Measuring the qubit in the computational basis yields 0 with probability ∣α∣2|\alpha|^2 and 1 with probability ∣β∣2|\beta|^2. It does not reveal the amplitudes themselves.

For nn qubits, there are N=2nN=2^n computational basis states, one for every nn-bit string. A general state is

∣ψ⟩=∑x∈{0,1}nαx∣x⟩,∑x∣αx∣2=1.|\psi\rangle=\sum_{x\in\{0,1\}^n}\alpha_x|x\rangle,\qquad\sum_x|\alpha_x|^2=1.

Although 2n2^n amplitudes appear in this expression, one measurement returns only one string xx, with probability ∣αx∣2|\alpha_x|^2. This is why simply preparing every possible input in superposition does not immediately solve search.

Example (Why phase matters).

The states ∣+⟩=(∣0⟩+∣1⟩)/2|+\rangle=(|0\rangle+|1\rangle)/\sqrt2 and ∣−⟩=(∣0⟩−∣1⟩)/2|-\rangle=(|0\rangle-|1\rangle)/\sqrt2 both give a fair coin under a direct measurement. They are not the same state. A later interference operation can distinguish them. Grover's algorithm first changes a sign (a phase) and then converts that change into a larger probability of measuring the desired input.

Reversible operations and basic gates

Between measurements, quantum states evolve by a unitary matrix UU satisfying U†U=IU^\dagger U=I. Hence ∥U∣ψ⟩∥=∥∣ψ⟩∥\|U|\psi\rangle\|=\||\psi\rangle\|: the total measurement probability remains 1. A quantum operation acts linearly, so the same gate transforms each term of a superposition and adds the results.

GateEffectRole here

The Hadamard matrix is

H=12(111−1),H2=I.H=\frac{1}{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix},\qquad H^2=I.

Applying a Hadamard gate to every qubit initialized to zero creates the uniform superposition:

∣s⟩:=H⊗n∣0n⟩=1N∑x∈{0,1}n∣x⟩.|s\rangle:=H^{\otimes n}|0^n\rangle=\frac{1}{\sqrt N}\sum_{x\in\{0,1\}^n}|x\rangle.

Every candidate now has equal measurement probability 1/N1/N. The useful part of the algorithm is not preparing this state, but changing its amplitudes by controlled interference.

How a Boolean function becomes a quantum oracle

A general Boolean function need not be reversible: different inputs can have the same output. To evaluate it coherently, we use an additional qubit and define the reversible oracle

Uf∣x,b⟩=∣x,b⊕f(x)⟩,b∈{0,1}.U_f|x,b\rangle=|x,b\oplus f(x)\rangle,\qquad b\in\{0,1\}.

Prepare the extra qubit in ∣−⟩=(∣0⟩−∣1⟩)/2|-\rangle=(|0\rangle-|1\rangle)/\sqrt2. If f(x)=0f(x)=0, the extra qubit is unchanged. If f(x)=1f(x)=1, the XOR flips it, but X∣−⟩=−∣−⟩X|-\rangle=-|-\rangle. Therefore

Uf(∣x⟩∣−⟩)=(−1)f(x)∣x⟩∣−⟩.U_f\bigl(|x\rangle|-\rangle\bigr)=(-1)^{f(x)}|x\rangle|-\rangle.

The extra qubit factors out, and the input register receives a phase flip exactly when f(x)=1f(x)=1. On that register alone, this is the phase oracle

Of∣x⟩=(−1)f(x)∣x⟩.O_f|x\rangle=(-1)^{f(x)}|x\rangle.

Importantly, the oracle changes the sign of marked amplitudes, not their magnitudes. Measurement immediately after the phase oracle is no more likely to find a solution than before it. The second operation in Grover's algorithm fixes this.

Grover's Algorithm

Reflection about the uniform state

Define the diffusion operator DD by [Grover, 1996]

D=2∣s⟩⟨s∣−I.D=2|s\rangle\langle s|-I.

This operator is a reflection: it preserves the component of a state parallel to ∣s⟩|s\rangle and negates every perpendicular component. It is unitary because D2=ID^2=I.

Lemma 3 (Inversion about the mean).

If ∣ψ⟩=∑xαx∣x⟩|\psi\rangle=\sum_x\alpha_x|x\rangle and αˉ=N−1∑xαx\bar\alpha=N^{-1}\sum_x\alpha_x, then after applying DD, the amplitude of ∣x⟩|x\rangle is

αx′=2αˉ−αx.\alpha'_x=2\bar\alpha-\alpha_x.

Thus every amplitude is reflected across their common average.

Proof. By the definition of ∣s⟩|s\rangle,

⟨s∣ψ⟩=1N∑xαx=N αˉ.\langle s|\psi\rangle=\frac1{\sqrt N}\sum_x\alpha_x=\sqrt N\,\bar\alpha.

The amplitude of ∣x⟩|x\rangle in 2∣s⟩⟨s∣ψ⟩2|s\rangle\langle s|\psi\rangle is 2αˉ2\bar\alpha, and the amplitude in −∣ψ⟩-|\psi\rangle is −αx-\alpha_x. Their sum is 2αˉ−αx2\bar\alpha-\alpha_x. □\square

The diffusion operator can be implemented from Hadamards and a selective phase operation:

D=H⊗n(2∣0n⟩⟨0n∣−I)H⊗n.D=H^{\otimes n}\bigl(2|0^n\rangle\langle0^n|-I\bigr)H^{\otimes n}.

The middle operation flips the sign of every basis state except ∣0n⟩|0^n\rangle; up to an irrelevant global minus sign, it is the usual multi-controlled phase flip on ∣0n⟩|0^n\rangle. With an appropriate standard gate set, its implementation uses polynomially many elementary gates.

One Grover iteration

One iteration consists of two reflections, applied in this order:

G=DOf.G=D O_f.
  1. Oracle: negate the amplitude of each marked input.
  2. Diffusion: reflect every resulting amplitude across their average.

The first step makes a marked amplitude negative. Since the average is still positive when relatively few inputs are marked, the second step raises the marked amplitude above the rest. Repeating the two steps makes the probability of observing a marked input increase—up to a point.

Algorithm 4 (Grover search; MM known).
Input: an n-bit oracle f with M marked inputs, 0 < M < N
N ← 2^n
θ ← arcsin(√(M / N))
t ← max(0, nearest integer to π/(4θ) − 1/2)

Prepare n qubits in |0...0⟩
Apply H to every qubit             // prepare |s⟩
Repeat t times:
    Apply the phase oracle O_f     // flip marked signs
    Apply diffusion D             // reflect about |s⟩
Measure the register and obtain x
Check f(x); accept x only if f(x) = 1

Each iteration uses one phase-oracle call and one diffusion operation. When the number of marked inputs is unknown, use a variable-iteration search routine rather than assuming M=1M=1. If M=0M=0, no algorithm can return a valid marked item.

A four-item example

Take N=4N=4 and mark just x=11x=11. Initially, each state has amplitude 1/21/2. The phase oracle changes the amplitude of ∣11⟩|11\rangle to −1/2-1/2, leaving the other three at 1/21/2. Their average is

αˉ=3(1/2)−1/24=14.\bar\alpha=\frac{3(1/2)-1/2}{4}=\frac14.

Reflect across that average. For the marked state, the new amplitude is 2(1/4)−(−1/2)=12(1/4)-(-1/2)=1. For every unmarked state, it is 2(1/4)−1/2=02(1/4)-1/2=0. The final state is exactly ∣11⟩|11\rangle; a single Grover iteration succeeds with probability 1.

This is not a general guarantee of certainty after one round. It is a special small example. The next theorem gives the probability after any number of iterations.

Success Probability

Why the state stays two-dimensional

Suppose 0<M<N0<M<N. Split the basis into marked and unmarked states and define two normalized vectors:

∣G⟩=1M∑f(x)=1∣x⟩,∣B⟩=1N−M∑f(x)=0∣x⟩.|G\rangle=\frac1{\sqrt M}\sum_{f(x)=1}|x\rangle,\qquad |B\rangle=\frac1{\sqrt{N-M}}\sum_{f(x)=0}|x\rangle.

They are orthogonal because they have disjoint supports. The initial uniform state is a combination of these two vectors:

∣s⟩=MN∣G⟩+N−MN∣B⟩=sin⁡θ∣G⟩+cos⁡θ∣B⟩,|s\rangle=\sqrt{\frac MN}|G\rangle+\sqrt{\frac{N-M}{N}}|B\rangle=\sin\theta|G\rangle+\cos\theta|B\rangle,

where θ=arcsin⁡M/N\theta=\arcsin\sqrt{M/N}. The oracle flips ∣G⟩|G\rangle but not ∣B⟩|B\rangle, and the diffusion operator reflects about ∣s⟩|s\rangle. Thus both operations preserve the plane spanned by ∣G⟩|G\rangle and ∣B⟩|B\rangle, even though the full state space has dimension 2n2^n. This reduction is the reason the analysis becomes simple.

Two reflections compose to a rotation

Theorem 5 (Grover's exact success probability).

Let 0<M<N0<M<N, sin⁡2θ=M/N\sin^2\theta=M/N, and start in ∣s⟩|s\rangle. After tt applications of G=DOfG=DO_f,

Gt∣s⟩=sin⁡((2t+1)θ)∣G⟩+cos⁡((2t+1)θ)∣B⟩.G^t|s\rangle=\sin((2t+1)\theta)|G\rangle+\cos((2t+1)\theta)|B\rangle.

Consequently, the probability that the measurement produces a marked item is exactly

pt=sin⁡2((2t+1)θ).\boxed{p_t=\sin^2((2t+1)\theta)}.
[BBHT, 1998]

Proof. Work in the ordered orthonormal basis (∣G⟩,∣B⟩)(|G\rangle,|B\rangle). In these coordinates, the phase oracle and the uniform state are

Of=(−1001),∣s⟩=(sin⁡θcos⁡θ).O_f=\begin{pmatrix}-1&0\\0&1\end{pmatrix},\qquad |s\rangle=\begin{pmatrix}\sin\theta\\\cos\theta\end{pmatrix}.

Expanding D=2∣s⟩⟨s∣−ID=2|s\rangle\langle s|-I gives

D=(−cos⁡(2θ)sin⁡(2θ)sin⁡(2θ)cos⁡(2θ)).D=\begin{pmatrix}-\cos(2\theta)&\sin(2\theta)\\\sin(2\theta)&\cos(2\theta)\end{pmatrix}.

Multiplying in the order prescribed by the algorithm,

G=DOf=(cos⁡(2θ)sin⁡(2θ)−sin⁡(2θ)cos⁡(2θ)).G=DO_f=\begin{pmatrix}\cos(2\theta)&\sin(2\theta)\\-\sin(2\theta)&\cos(2\theta)\end{pmatrix}.

Now multiply this matrix by a vector (sin⁡ϕ,cos⁡ϕ)T(\sin\phi,\cos\phi)^\mathsf T. The angle-addition identities show that the result is (sin⁡(ϕ+2θ),cos⁡(ϕ+2θ))T(\sin(\phi+2\theta),\cos(\phi+2\theta))^\mathsf T. Each iteration therefore increases the angle from the bad axis by 2θ2\theta. We begin at angle θ\theta, so after tt iterations the angle is (2t+1)θ(2t+1)\theta. A measurement returns a marked input exactly when the state projects onto ∣G⟩|G\rangle, giving probability sin⁡2((2t+1)θ)\sin^2((2t+1)\theta). □\square

Choosing when to measure

The marked probability is close to 1 when (2t+1)θ(2t+1)\theta is close to π/2\pi/2. A near-optimal integer choice is

t≈π4θ−12.t\approx\frac\pi{4\theta}-\frac12.

For M≪NM\ll N, the small-angle approximation θ≈M/N\theta\approx\sqrt{M/N} gives

t=Θ ⁣(NM).t=\Theta\!\left(\sqrt{\frac NM}\right).

In particular, for a unique marked item M=1M=1, the query count is Θ(N)\Theta(\sqrt N). If M≤N/2M\le N/2 and we round to the nearest nonnegative integer, the angular error is at most θ\theta, so the success probability is at least cos⁡2θ=1−M/N\cos^2\theta=1-M/N. If M>N/2M>N/2, simply measuring the initial state already succeeds with probability greater than 1/21/2.

Why not keep iterating? After the angle passes π/2\pi/2, the probability decreases again. Grover's algorithm oscillates because all its operations are unitary; it does not monotonically amplify a state forever.

The marked-state probability is the square of the vertical component of the state vector. Unlike ordinary accumulation, quantum amplitude amplification is reversible: another iteration can reduce it.

Why does the probability fall after the peak? One Grover iteration is the product of two reflections, hence a rotation by twice the initial angle in the plane spanned by the uniform marked and unmarked states. It does not stop at the answer: after the state vector passes the marked axis, its vertical component shrinks. Measurement depends on the square of that component, so the success probability decreases. The state is not being degraded; the unitary operation is simply overshooting its target. Quantum Query Lower Bound

Grover's algorithm supplies an upper bound. For a matching lower bound we must rule out every possible quantum strategy, not only algorithms that resemble Grover's rotations. This is the central complexity-theoretic result. [Bennett–Bernstein–Brassard–Vazirani, 1997]

Theorem 6 (Quantum query optimality).

An algorithm that finds the unique marked location among NN possibilities with probability at least 2/32/3 for every possible location requires Q=Ω(N)Q=\Omega(\sqrt N) quantum oracle calls. Grover's O(N)O(\sqrt N) algorithm is therefore query-optimal: bounded-error unique search has quantum query complexity Θ(N)\Theta(\sqrt N).

Comparison with an empty oracle

For a potential marked address jj, define the phase oracle Oj=I−2ΠjO_j=I-2\Pi_j, where Πj\Pi_j projects onto the states whose query-address register equals jj. Ancilla registers are unrestricted. Define O∅=IO_\varnothing=I as the empty oracle; it is used only as a reference, not as an allowed instance of the unique-search promise.

Let an arbitrary algorithm make QQ oracle queries, with any fixed unitaries between calls. Let ∣ψQ(j)⟩|\psi_Q^{(j)}\rangle and ∣ψQ(∅)⟩|\psi_Q^{(\varnothing)}\rangle denote the final pure states under these two oracles. Intermediate measurements can be deferred to the end by storing their outcomes coherently. For each query index k∈{1,…,Q}k\in\{1,\ldots,Q\}, let ∣ϕk⟩|\phi_k\rangle be the state just before the kk-th query in the empty-oracle computation, and put

qk,j:=∥Πj∣ϕk⟩∥2,∑j=1Nqk,j=1.q_{k,j}:=\|\Pi_j|\phi_k\rangle\|^2,\qquad \sum_{j=1}^N q_{k,j}=1.

Here qk,jq_{k,j} is a probability, whereas its square root is an amplitude norm. The square root is exactly where the N\sqrt N behavior enters: a single query can affect many addresses in superposition, but the sum of their squared amplitude norms is only 1.

Lemma 7 (Hybrid distance estimate).

For each mark jj, let Δj=∥∣ψQ(j)⟩−∣ψQ(∅)⟩∥\Delta_j=\bigl\||\psi_Q^{(j)}\rangle-|\psi_Q^{(\varnothing)}\rangle\bigr\|. Then

Δj≤2∑k=1Qqk,j,∑j=1NΔj2≤4Q2.\Delta_j\le2\sum_{k=1}^Q\sqrt{q_{k,j}},\qquad \sum_{j=1}^N\Delta_j^2\le4Q^2.
Proof of the hybrid lemma

Compare computations that use OjO_j and O∅O_\varnothing throughout. Let dkd_k be their Euclidean state distance immediately after the first kk queries and associated fixed unitaries, with d0=0d_0=0. Before query kk, write the two states as ∣uk⟩|u_k\rangle (marked) and ∣ϕk⟩|\phi_k\rangle (empty). They are at distance dk−1d_{k-1}, since the intervening unitary preserves norms. The triangle inequality gives the missing step explicitly:

dk=∥Oj∣uk⟩−I∣ϕk⟩∥≤∥Oj(∣uk⟩−∣ϕk⟩)∥+∥(Oj−I)∣ϕk⟩∥=dk−1+2∥Πj∣ϕk⟩∥=dk−1+2qk,j.\begin{aligned} d_k&=\|O_j|u_k\rangle-I|\phi_k\rangle\|\\ &\le\|O_j(|u_k\rangle-|\phi_k\rangle)\|+\|(O_j-I)|\phi_k\rangle\|\\ &=d_{k-1}+2\|\Pi_j|\phi_k\rangle\|=d_{k-1}+2\sqrt{q_{k,j}}. \end{aligned}

Iterating this recurrence from d0=0d_0=0 proves the first claim. Cauchy–Schwarz then gives

Δj2≤4(∑k=1Qqk,j)2≤4Q∑k=1Qqk,j.\Delta_j^2\le4\left(\sum_{k=1}^Q\sqrt{q_{k,j}}\right)^2\le4Q\sum_{k=1}^Qq_{k,j}.

Sum over jj. Since ∑jqk,j=1\sum_j q_{k,j}=1 for each fixed kk, we obtain ∑jΔj2≤4Q⋅Q=4Q2\sum_j\Delta_j^2\le4Q\cdot Q=4Q^2. No computational assumption was made about the intervening unitaries. □

From state distance to query complexity

Proof of the quantum lower bound

Let EjE_j be the projection onto the final measurement outcomes in which the algorithm reports location jj. (A general measurement can be represented by a projective one on an extended workspace.) Write pj=∥Ej∣ψQ(j)⟩∥2p_j=\|E_j|\psi_Q^{(j)}\rangle\|^2 and rj=∥Ej∣ψQ(∅)⟩∥2r_j=\|E_j|\psi_Q^{(\varnothing)}\rangle\|^2. Because different reports are disjoint, ∑jrj≤1\sum_j r_j\le1. The triangle inequality and contraction of projections imply

pj≤rj+Δj,pj≤2rj+2Δj2.\sqrt{p_j}\le\sqrt{r_j}+\Delta_j,\qquad p_j\le2r_j+2\Delta_j^2.

Summing over all marked addresses and applying the Lemma 7: hybrid lemma gives

∑j=1Npj≤2∑jrj+2∑jΔj2≤2+8Q2.\sum_{j=1}^Np_j\le2\sum_jr_j+2\sum_j\Delta_j^2\le2+8Q^2.

By the success requirement, pj≥2/3p_j\ge2/3 for each jj. Hence 2N/3≤2+8Q22N/3\le2+8Q^2, so

Q≥N/12−1/4=Ω(N).Q\ge\sqrt{N/12-1/4}=\Omega(\sqrt N).

This proves Theorem 6: the quantum query lower bound. Notice the contrast: the classical adversary counts the fraction of addresses queried, while the quantum hybrid argument controls changes of amplitude. □

Oracle convention. This section uses a phase oracle. The same inequality needed later for relative complexity classes holds for the standard bit oracle Uf∣x,b⟩=∣x,b⊕f(x)⟩U_f|x,b\rangle=|x,b\oplus f(x)\rangle, since changing the value at address jj affects only the query-register subspace Πj\Pi_j, and the difference of the two oracle unitaries has operator norm at most 2 there. Thus the hybrid proof applies to algorithms with ordinary Boolean oracle access as well.

Scope of the theorem. It is an unconditional lower bound for black-box queries. It does not claim an unconditional exponential lower bound for SAT on an explicitly given formula; the formula may contain structure inaccessible in the oracle model. [CS455 reductions notes; BBBV, 1997]

Complexity Classes

From query complexity to time and space

Complexity classes use the bit length of an explicit input as the resource parameter. In particular, P is deterministic polynomial time, NP admits polynomially checkable witnesses, BPP is bounded-error randomized polynomial time, and BQP is bounded-error uniform quantum polynomial time. PSPACE is deterministic polynomial space. Oracle classes such as NPA\mathrm{NP}^A allow their machines to query a fixed set AA in one oracle step. This is the same resource-comparison viewpoint used in the course's discussion of reductions and completeness. [CS455 reductions notes; Bernstein–Vazirani, 1997]

Unconditionally, P⊆BPP⊆BQP⊆PSPACE\mathrm P\subseteq\mathrm{BPP}\subseteq\mathrm{BQP}\subseteq\mathrm{PSPACE}. We prove the last inclusion rather than simply listing it.

Theorem 8 (Polynomial-space simulation of quantum circuits).

BQP⊆PSPACE\mathrm{BQP}\subseteq\mathrm{PSPACE}. More generally, for a classical oracle AA, BQPA⊆PSPACEA\mathrm{BQP}^A\subseteq\mathrm{PSPACE}^A. [Bernstein–Vazirani, 1997]

Proof: sum over computational paths

Fix a polynomial-time uniform quantum circuit on an nn-bit input. It acts on m=poly⁡(n)m=\operatorname{poly}(n) qubits and uses L=poly⁡(n)L=\operatorname{poly}(n) elementary gates from a fixed finite gate set with efficiently computable entries. A matrix entry of a constant-size local gate can be evaluated to bb bits in space poly⁡(n+b)\operatorname{poly}(n+b). Deferring measurement lets us assume a final output measurement.

For final basis state zz, expand its amplitude as a sum over intermediate computational-basis configurations z1,…,zL−1z_1,\ldots,z_{L-1}:

αz=∑z1,…,zL−1∏k=1L⟨zk∣Uk∣zk−1⟩,z0=initial state, zL=z.\alpha_z=\sum_{z_1,\ldots,z_{L-1}}\prod_{k=1}^L\langle z_k|U_k|z_{k-1}\rangle,\quad z_0=\text{initial state},\ z_L=z.

There are exponentially many terms, but we do not store them. A depth-first enumeration uses polynomial space: each path has LL configurations of mm bits; gate entries and the running complex sum are stored at polynomial precision. There can be at most 2m(L−1)2^{m(L-1)} path terms, each of magnitude at most 1. Choose a per-final-amplitude error target ε=2−m−10\varepsilon=2^{-m-10}. Keeping b=O(mL+m)b=O(mL+m) bits of numerical precision is enough to offset the exponentially many additions and approximate each αz\alpha_z to within ε\varepsilon, while using only polynomial space.

Next enumerate accepting final configurations zz in that same space and sum the approximations to ∣αz∣2|\alpha_z|^2. Since ∣αz∣≤1|\alpha_z|\le1, the change in each squared magnitude is at most 2ε+ε22\varepsilon+\varepsilon^2. Summing over at most 2m2^m outputs incurs less than 1/1001/100 total error; keep a few extra guard bits for rounding. Thus we approximate the acceptance probability with error below 1/201/20. Since the true acceptance probability is at least 2/32/3 on yes-instances and at most 1/31/3 on no-instances, comparing the approximation with 1/21/2 decides the language. The computation may take exponential time, but uses polynomial space.

With an oracle AA, each queried matrix entry can be computed by asking the same oracle during this enumeration. The argument therefore relativizes. □

What Grover does—and does not—imply for SAT

For a formula FF on nn Boolean variables, let fF(x)=1f_F(x)=1 exactly when assignment xx satisfies FF. A reversible implementation of its polynomial-time verifier gives the coherent oracle needed for Grover. Searching N=2nN=2^n assignments costs at most O(2n/2)O(2^{n/2}) oracle calls and O(2n/2poly⁡(∣F∣))O(2^{n/2}\operatorname{poly}(|F|)) gates up to standard implementation overhead. If there are no solutions, every measured candidate fails classical verification. The unknown-solution-count schedule in Theorem 12: the variable-iteration theorem provides a bounded-error decision procedure. [Grover, 1996; BBHT, 1998]

SAT is NP-complete under polynomial-time many-one reductions. That is a statement about explicit instances and the ability to transfer hardness or algorithms across them. It is not the same as Grover's query optimality in Theorem 6: the quantum query theorem. Since 2n/22^{n/2} is still exponential in nn, the algorithm does not place SAT—or NP—inside BQP.

An arbitrary NP verifier

Given L∈NPL\in\mathrm{NP}, let V(x,w)V(x,w) be its polynomial-time witness verifier with witness length at most m(n)=poly⁡(n)m(n)=\operatorname{poly}(n), where n=∣x∣n=|x|. Pad shorter witnesses to exactly m(n)m(n) bits and search over them with predicate fx(w)=V(x,w)f_x(w)=V(x,w). The number of candidates is 2m(n)2^{m(n)}. By the variable-iteration search procedure below, we can find a valid witness with bounded error, or reject when there is none, within

O(2m(n)/2poly⁡(n))O\bigl(2^{m(n)/2}\operatorname{poly}(n)\bigr)

quantum time. This improves generic exhaustive witness enumeration quadratically in the number of candidates, but need not be polynomial in the original input length. If m(n)=Θ(n2)m(n)=\Theta(n^2), for instance, the generic bound remains 2Θ(n2)2^{\Theta(n^2)}.

The query setting hides structure by design. An explicit SAT formula may reveal useful structure directly. Hence the lower bound in Theorem 6: the query theorem cannot exclude a better algorithm for SAT, and the unrelativized NP-versus-BQP question remains open.

An oracle where NP is not contained in BQP

We can use the hybrid lemma to obtain a genuine complexity-class separation relative to an oracle—a stronger consequence than merely stating that one query task is hard. The construction is a diagonalization over polynomial-time quantum oracle machines. [BBBV, 1997]

Proof of Lemma 9

Since both states are normalized, Re⁡⟨ψ−φ∣ψ+φ⟩=0\operatorname{Re}\langle\psi-\varphi|\psi+\varphi\rangle=0. Also, 2E−I2E-I is a unitary reflection. Thus

∣∥Eψ∥2−∥Eφ∥2∣=12∣Re⁡⟨ψ−φ∣(2E−I)∣ψ+φ⟩∣≤12∥ψ−φ∥ ∥ψ+φ∥(Cauchy–Schwarz)≤∥ψ−φ∥.□\begin{aligned} \bigl|\|E\psi\|^2-\|E\varphi\|^2\bigr| &=\tfrac12\bigl|\operatorname{Re}\langle\psi-\varphi|(2E-I)|\psi+\varphi\rangle\bigr|\\ &\le\tfrac12\|\psi-\varphi\|\,\|\psi+\varphi\|\qquad\text{(Cauchy--Schwarz)}\\ &\le\|\psi-\varphi\|. \qquad\square \end{aligned}
Lemma 9 (Measurement probability stability).

Let ∣ψ⟩|\psi\rangle and ∣φ⟩|\varphi\rangle be normalized pure states and EE the projector associated with a measurement outcome. Then

∣∥E∣ψ⟩∥2−∥E∣φ⟩∥2∣≤∥∣ψ⟩−∣φ⟩∥.\bigl|\|E|\psi\rangle\|^2-\|E|\varphi\rangle\|^2\bigr|\le\bigl\||\psi\rangle-|\varphi\rangle\bigr\|.

The same applies to any outcome of a general measurement after introducing an ancilla that realizes that measurement projectively.

Theorem 10 (Oracle separating NP from BQP).

There exists a Boolean oracle AA such that NPA⊈BQPA\mathrm{NP}^A\nsubseteq\mathrm{BQP}^A.

Proof idea. At a carefully chosen length, hide one marked string among exponentially many possible oracle addresses while giving the next clocked quantum machine only polynomially many queries. The hybrid lemma says there is a marked address it can barely detect; we choose that address (or no address) to make the machine fail.

Proof: diagonalize using the hybrid lemma

For each oracle AA, define the unary language

LA:={1n:∃y∈{0,1}n with A(y)=1}.L_A:=\{1^n:\exists y\in\{0,1\}^n\text{ with }A(y)=1\}.

It belongs to NPA\mathrm{NP}^A: on input 1n1^n, nondeterministically guess an nn-bit string yy and query A(y)A(y). Enumerate all clocked polynomial-time quantum oracle machines Q1,Q2,…Q_1,Q_2,\ldots, each paired with an explicit polynomial clock bound pi(n)p_i(n) on its running time and number of oracle queries. This enumeration is effective because it constrains running time syntactically, not by a semantic promise of bounded error. Every language in BQP relative to any oracle is decided by a machine in this enumeration. We build AA in stages, freezing each decided oracle bit forever.

Stage ii. Choose a fresh input length nin_i larger than any length fixed at previous stages and sufficiently large that

2pi(ni)2ni<16.\frac{2p_i(n_i)}{\sqrt{2^{n_i}}}<\frac16.

Temporarily assign zero to all previously undefined strings of length at most pi(ni)p_i(n_i), leaving all strings of length nin_i zero as well, and run QiQ_i on 1ni1^{n_i}. Let a0a_0 be its acceptance probability. Quantum queries to strings longer than pi(ni)p_i(n_i) cannot occur, because writing such an address would exceed the time bound.

If a0≥1/2a_0\ge1/2, permanently freeze the current length-nin_i oracle block to zero. Then 1ni∉LA1^{n_i}\notin L_A, but QiQ_i accepts it too often to meet the required BQP error bound.

If a0<1/2a_0<1/2, compare this computation with a hypothetical oracle that differs at exactly one of the 2ni2^{n_i} length-nin_i strings. By the Lemma 7: hybrid lemma, averaged over those possible changes the final-state distance is at most 2pi(ni)/2ni<1/62p_i(n_i)/\sqrt{2^{n_i}}<1/6. Hence at least one string yiy_i can be switched to 1 while changing the acceptance probability by less than 1/61/6. (By Lemma 9, an outcome’s probability changes by at most the Euclidean distance of the two final states.) Under that choice, 1ni∈LA1^{n_i}\in L_A but the machine accepts with probability below 1/2+1/6=2/31/2+1/6=2/3. Freeze this length block accordingly.

Finally freeze all other still-undefined oracle bits at lengths no greater than pi(ni)p_i(n_i) (except the chosen yiy_i, if any). Since later stages only affect longer, unexamined strings, QiQ_i's behavior on 1ni1^{n_i} can never change. Every QiQ_i fails at its designated length, so no bounded-error polynomial-time quantum oracle machine decides LAL_A. Therefore LA∈NPA∖BQPAL_A\in\mathrm{NP}^A\setminus\mathrm{BQP}^A. □

Why the query lower bound applies here. Quantum oracle machines use the standard bit oracle, not necessarily a phase oracle. The Lemma 7: hybrid recurrence still bounds the change at a single address by twice the norm of the amplitude querying that address; the same averaging argument then works for the stage construction.

An oracle where the classes collapse

An oracle can change the situation in the other direction. This yields the precise limitation of relativizing proof techniques—not a claim that either unrelativized containment holds.

Theorem 11 (PSPACE-complete collapse oracle).

Let BB be any PSPACE-complete language under polynomial-time mapping reductions. Then

PB=NPB=BQPB=PSPACE.\mathrm P^B=\mathrm{NP}^B=\mathrm{BQP}^B=\mathrm{PSPACE}.
Proof: simulate the oracle and use completeness

First, every PSPACE language many-one reduces to BB in polynomial time, so a polynomial-time machine asking BB questions decides it: PSPACE⊆PB\mathrm{PSPACE}\subseteq\mathrm P^B. Conversely, since B∈PSPACEB\in\mathrm{PSPACE}, each polynomially long query to BB can be evaluated in polynomial space, and a polynomial-time oracle computation can be simulated using polynomial space. Thus PB=PSPACE\mathrm P^B=\mathrm{PSPACE}.

The same reasoning gives PSPACEB=PSPACE\mathrm{PSPACE}^B=\mathrm{PSPACE}: polynomial-space oracle computations can be simulated with a polynomial-space subroutine for BB, reusing work tape after each call. Nondeterministic polynomial time with oracle BB is contained in PSPACEB\mathrm{PSPACE}^B by exhaustive depth-first simulation, so

PB⊆NPB⊆PSPACEB=PSPACE=PB.\mathrm P^B\subseteq\mathrm{NP}^B\subseteq\mathrm{PSPACE}^B=\mathrm{PSPACE}=\mathrm P^B.

Finally, PB⊆BQPB\mathrm P^B\subseteq\mathrm{BQP}^B trivially, while the relativized Theorem 8: quantum space simulation gives BQPB⊆PSPACEB=PSPACE\mathrm{BQP}^B\subseteq\mathrm{PSPACE}^B=\mathrm{PSPACE}. Hence all four classes coincide. □

Consequence. The Theorem 10: separation oracle and Theorem 11: collapse oracle give incompatible relativized answers to whether NP is contained in BQP. Therefore a method that proves the same statement relative to every oracle cannot settle that containment one way or the other. This does not prove that the unrelativized question is independent or unanswerable.

Variants and Pitfalls

More than one marked element

The exact theorem already covers M>1M>1: the angle is θ=arcsin⁡M/N\theta=\arcsin\sqrt{M/N}, so fewer iterations are needed when a larger fraction of inputs are marked. When M=NM=N, every input works and one can simply output any input. The case M=0M=0 has no valid output.

Unknown number of solutions

When MM is unknown, choosing a fixed number of Grover iterations based on a guess can overshoot the success peak. Randomizing the number of iterations avoids this problem. The method below is due to Boyer, Brassard, Høyer, and Tapp. [BBHT, 1998]

Theorem 12 (Search with unknown number of marked inputs).

Without knowing MM, a randomized Grover search that verifies each candidate finds a marked input with expected O(N/M)O(\sqrt{N/M}) oracle calls whenever 1≤M≤N1\le M\le N. With an O(N)O(\sqrt N) query budget it can decide whether any marked item exists with bounded error, and it never reports a false positive.

Algorithm 13 (Random-iteration search).
m ← 1
repeat:
    Sample a uniformly random x and test f(x); return if marked
    Choose r uniformly from {0,...,m−1}
    Prepare the uniform state |s⟩
    Apply r Grover iterations, then measure x
    If f(x) = 1, return x
    m ← min(ceil((6/5) · m), ceil(sqrt(N)))

For decision: stop after a fixed O(sqrt(N)) budget.
If no verified x was found, reject.
Proof: a random iteration count suppresses overshooting

Put θ=arcsin⁡M/N\theta=\arcsin\sqrt{M/N}. By Theorem 5: the exact probability formula, choosing rr uniformly from {0,…,m−1}\{0,\ldots,m-1\} gives success probability

Pm=1m∑r=0m−1sin⁡2((2r+1)θ)=12−sin⁡(4mθ)4msin⁡(2θ).\begin{aligned} P_m&=\frac1m\sum_{r=0}^{m-1}\sin^2((2r+1)\theta)\\ &=\frac12-\frac{\sin(4m\theta)}{4m\sin(2\theta)}. \end{aligned}

The equality follows by writing sin⁡2u=(1−cos⁡2u)/2\sin^2u=(1-\cos2u)/2 and summing a geometric progression of cosines. If M≤N/2M\le N/2 then sin⁡(2θ)=2(M/N)(1−M/N)=Ω(M/N)\sin(2\theta)=2\sqrt{(M/N)(1-M/N)}=\Omega(\sqrt{M/N}). Once m≥1/sin⁡(2θ)m\ge1/\sin(2\theta), the displayed formula implies Pm≥1/4P_m\ge1/4. The first such stage has m=O(N/M)m=O(\sqrt{N/M}), and the total number of oracle calls in earlier stages is a geometric sum of the same order.

Beyond that stage, each independent trial succeeds with probability at least 1/41/4. Because mm grows by the factor 6/56/5 while the chance of surviving kk more failed stages is at most (3/4)k(3/4)^k, the expected additional work is bounded by a convergent geometric series with ratio (6/5)(3/4)=9/10<1(6/5)(3/4)=9/10<1. Thus the expected total is O(N/M)O(\sqrt{N/M}). For M>N/2M>N/2, the additional uniform classical sample at the start of every stage succeeds with probability greater than 1/21/2, independently of the Grover trial. Since each failed stage costs at most a factor 6/56/5 more than the previous stage, expected work is again a convergent geometric sum and is constant in this case.

If M=0M=0, every verified test fails and the procedure would otherwise run indefinitely. For a decision algorithm impose the stated O(N)O(\sqrt N) budget, including a constant number of trials at m≈Nm\approx\sqrt N. For M≥1M\ge1, the probability of missing every marked input is then bounded below 1 by a fixed constant, and independent restarts reduce it to at most 1/31/3. For M=0M=0, verification guarantees rejection. □

Verification and bounded error

A measurement can return an unmarked input even when solutions exist. Because f(x)f(x) can be evaluated, the proposed answer can be checked. Repeating an independent constant-success search reduces the failure probability exponentially in the number of repetitions. Repetition does not bypass the Ω(N)\Omega(\sqrt N) asymptotic query lower bound for constant success.

The four statements not to confuse

  1. Preparing 2n2^n amplitudes is not equivalent to learning 2n2^n classical answers.
  2. A quadratic query advantage does not imply a polynomial-time algorithm in the input length nn.
  3. A lower bound for unstructured search does not automatically lower-bound algorithms exploiting structured SAT formulas.
  4. The fact that Grover is optimal in its model does not imply NP-complete problems are outside BQP.

Exercises

  1. Qubit interference. Compute H∣+⟩H|+\rangle and H∣−⟩H|-\rangle. Why can these two states be distinguished even though their direct measurement probabilities agree?
    Solution

    Because H2=IH^2=I, H∣+⟩=∣0⟩H|+\rangle=|0\rangle and H∣−⟩=∣1⟩H|-\rangle=|1\rangle. A Hadamard gate converts the relative sign into a certain computational-basis outcome.

  2. One round with N=8N=8. With one marked input, compute the average amplitude just after the phase oracle, then the amplitude on a marked input after diffusion.
    Solution

    The amplitude average is (8−2)/(88)=3/(48)(8-2)/(8\sqrt8)=3/(4\sqrt8). The marked amplitude becomes 2⋅3/(48)+1/8=5/(28)2\cdot3/(4\sqrt8)+1/\sqrt8=5/(2\sqrt8), with probability 25/3225/32.

  3. Two-dimensional invariant. Show that OfO_f and DD preserve span⁡{∣G⟩,∣B⟩}\operatorname{span}\{|G\rangle,|B\rangle\}.
    Solution

    OfO_f acts diagonally on ∣G⟩,∣B⟩|G\rangle,|B\rangle, so it preserves the span. Since ∣s⟩|s\rangle lies in the span, D∣v⟩=2∣s⟩⟨s∣v⟩−∣v⟩D|v\rangle=2|s\rangle\langle s|v\rangle-|v\rangle lies there for any ∣v⟩|v\rangle in the span as well.

  4. Best stopping time. Let N=16N=16 and M=1M=1. Calculate θ\theta and choose the integer tt closest to π/(4θ)−1/2\pi/(4\theta)-1/2. Compare ptp_t with pt+1p_{t+1}.
    Solution

    θ=arcsin⁡(1/4)\theta=\arcsin(1/4), about 0.25268. The suggested stopping time is t=3t=3; sin⁡2(7θ)≈0.9613\sin^2(7\theta)\approx0.9613, while sin⁡2(9θ)≈0.5817\sin^2(9\theta)\approx0.5817. One extra iteration reduces success.

  5. Where the lower bound uses normalization. Identify the exact place in the hybrid proof where the number of possible marks becomes relevant.
    Solution

    It is the equality ∑j=1Nqk,j=1\sum_{j=1}^Nq_{k,j}=1. Summing the squared distance bounds over all NN choices of marked item gives ∑jΔj2≤4Q2\sum_j\Delta_j^2\le4Q^2, while constant success for each of the NN choices forces a quantity of order NN on the other side.

  6. Complexity-theory distinction. Explain why O(2n/2poly⁡(n))O(2^{n/2}\operatorname{poly}(n)) is not a BQP upper bound for SAT.
    Solution

    BQP requires polynomial runtime in the input length. 2n/22^{n/2} is exponential in nn, so this speedup does not put SAT in BQP. In addition, the upper bound must account for the cost of realizing the verifier oracle.

Summary

  1. Quantum mechanics. A qubit is a unit vector. Measurement probabilities are squared amplitude magnitudes; the oracle changes phases and diffusion converts those changes into a measurable advantage.
  2. Grover rotation. Each Grover step rotates a two-dimensional state by 2θ2\theta, with sin⁡2θ=M/N\sin^2\theta=M/N. The exact probability formula in Theorem 5: the success theorem explains both amplification and overshooting.
  3. Sharp query bound. The Theorem 6: query-optimality theorem proves that unique black-box search needs Θ(N)\Theta(\sqrt N) quantum queries, versus Θ(N)\Theta(N) classical queries.
  4. Space and oracle complexity. Theorem 8: Quantum circuits use at most polynomial space to simulate. There is an Theorem 10: oracle separating NP from BQP and a Theorem 11: PSPACE oracle collapsing them. Thus relativizing arguments alone cannot settle the unrelativized containment.
  5. NP is still unresolved. Grover can search NP witnesses in exponential time with a halved witness-space exponent, but neither the algorithm nor its black-box lower bound determines whether NP⊆BQP\mathrm{NP}\subseteq\mathrm{BQP}.
